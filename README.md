## 📝 My Approach

For every problem I solve, I try to follow this process:

**Understand → Think → Code → Test → Optimize → Learn**

I will try to solve problems **on my own first** before looking at hints or solutions.

For each problem, I aim to understand:

* 🔹 What is the problem asking?
* 🔹 What is the brute-force approach?
* 🔹 Can it be optimized?
* 🔹 What is the time complexity?
* 🔹 What is the space complexity?
* 🔹 What did I learn from the problem?
